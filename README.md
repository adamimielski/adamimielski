# Adam Imielski

I run [EcomFlowLab](https://ecomflowlab.pl), a technical-care service for online stores in Poland. I build the unglamorous parts that make a shop actually run: integrations, catalog automation, migrations and technical SEO.

## What I work on

- **Marketplace & ERP integrations:** BaseLinker, Apilo, Shoper, WooCommerce, Allegro, wholesaler feeds (XML/CSV), Subiekt (via connectors). Stock and price sync on cron, reconciliation, alerts.
- **Catalog automation at scale:** merging size/colour SKUs into product variants through shop APIs (thousands of cards, zero manual clicking), category trees and attributes built for search.
- **Store migrations:** Shoper → WooCommerce with customers, order history, 1:1 URLs and 301 maps; hosting cutovers behind Cloudflare.
- **Technical SEO & AI visibility:** crawlability, structured data, cookieless analytics (self-hosted Umami), content that AI answers actually cite.
- **Automations:** carrier APIs (InPost, DPD), payment webhooks, order routing, email agents.

## Stack

Python · FastAPI · SQLite/PostgreSQL · REST/SOAP APIs · WordPress/WooCommerce · Docker · Linux VPS (Hetzner) · Cloudflare · Apache/LiteSpeed · cron
